## 🎯 核心亮点

### 1. 流式输出 + 语音播放

**业界首创**: 边接收 AI 回复边播放语音

**技术难点**:
- 智能分句（中文标点检测）
- 队列管理（不重复播放）
- 中断处理（新消息停止）

**用户体验**:
- 无需等待完整回复
- 自然流畅的播放
- 解放双手（听故事）

---

### 2. AI 自主调用工具

**核心能力**: AI 可以根据对话自主调用工具

**应用场景**:
```
孩子："我叫小明"
  → AI 调用 updateConfig
  → 更新配置 { childName: "小明" }
  → AI 回复："好的，小明！我记住了"

孩子："今天天气怎么样"
  → AI 调用 webSearch
  → 获取天气信息
  → AI 回复："今天晴朗..."

孩子："恐龙有什么知识"
  → AI 调用 knowledge
  → 查询知识库
  → AI 回复："恐龙是..."
```
